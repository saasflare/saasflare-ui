**128 components**, grouped below. Each is installable with `npx shadcn add` and fully themeable through the Saasflare design tokens.

## Brand & Auth

- [Social Auth Button](/docs/components/social-auth-button) — Provider-branded OAuth sign-in button for all 16 supported identity providers, with official brand logos, an opt-in colorful weight, and built-in loading state (wraps StatefulButton). Includes 16 pre-bound shortcuts (GoogleAuthButton, GitHubAuthButton, …).
- [Theme Mode Multi Toggle](/docs/components/theme-mode-multi-toggle) — Three-segment light / dark / system segmented control (Sun / Moon / Monitor) built on ToggleGroup, with icon, icon-inherit, and button appearances.
- [Theme Mode Toggle](/docs/components/theme-mode-toggle) — Two-state light/dark toggle button (Sun/Moon) backed by next-themes, with an SSR seed prop to eliminate the first-paint flash.

## Buttons & Actions

- [Button](/docs/components/button) — The core action element. Three orthogonal axes — variant × intent × size — plus loading and icon slots.
- [Button Group](/docs/components/button-group) — Visually connected strip of buttons with shared radii and separators. For segmented actions and toolbars.
- [Moving Border](/docs/components/moving-border) — Continuously rotating conic-gradient border around an element. Eye-catching CTA wrapper.
- [Scroll To Top Button](/docs/components/scroll-to-top-button) — Floating button that appears past a scroll offset and smoothly returns to the top — supports window or a custom scroll container, flat or glass surface.
- [Shimmer Button](/docs/components/shimmer-button) — CTA button with a looping diagonal light sweep. Draws the eye to your primary action.
- [Social Button](/docs/components/social-button) — Compact branded sign-in button for five core providers (Google, Apple, GitHub, Microsoft, Twitter) with official logos and brand colors. For the full 16-provider OAuth set, see Social Auth Button.
- [Stateful Button](/docs/components/stateful-button) — Button with a built-in async loading state — disables, sets aria-busy, prepends a spinner, and optionally swaps its label for loadingText.

## Forms & Inputs

- [Calendar](/docs/components/calendar) — Month-grid date calendar (react-day-picker) supporting single, multiple, or range selection.
- [Checkbox](/docs/components/checkbox) — Accessible checkbox with indeterminate state, for forms and bulk-select rows.
- [Combobox](/docs/components/combobox) — Searchable select — a Popover wrapping a cmdk palette. Autocomplete with full keyboard navigation.
- [Date Picker](/docs/components/date-picker) — Controlled/uncontrolled single-date input — Button + Popover + single-mode Calendar.
- [Date Range Picker](/docs/components/date-range-picker) — Controlled/uncontrolled date-range input — Button + Popover + range-mode Calendar.
- [Dropzone](/docs/components/dropzone) — Drag-and-drop file upload area with click-to-open fallback. Self-contained (no react-dropzone).
- [Field](/docs/components/field) — Form-field wrapper bundling label, control, description, and error message with correct a11y wiring.
- [Form](/docs/components/form) — react-hook-form integration layer — field context, labels, descriptions, and validation messages.
- [Input](/docs/components/input) — Single-line text field — the form workhorse — with intent states and full sizing support.
- [Input Group](/docs/components/input-group) — Wraps an input with addons, icons, and prefix/suffix elements into a single bordered unit.
- [Input OTP](/docs/components/input-otp) — One-time-code input with per-digit slots, paste handling, and auto-advance.
- [Label](/docs/components/label) — Accessible form label wired to its control, with required and disabled styling.
- [Multi Select](/docs/components/multi-select) — Searchable multi-select with chips, select-all, a max limit, and async option loading — built on Popover + cmdk, with a plain string[] value.
- [Native Select](/docs/components/native-select) — Lightweight native select with a chevron overlay — zero-JS dropdown for simple option lists.
- [Number Input](/docs/components/number-input) — Numeric input with ± stepper buttons, min/max clamping, configurable step + precision.
- [Radio Group](/docs/components/radio-group) — Mutually exclusive option set with keyboard arrow navigation and accessible grouping.
- [Rating](/docs/components/rating) — Star rating input with half-star precision, keyboard arrows, and read-only display mode.
- [Search Field](/docs/components/search-field) — Search input with built-in search icon, clear button, and optional loading spinner.
- [Select](/docs/components/select) — Dropdown select with option groups and a styled trigger. Radix-backed and fully accessible.
- [Slider](/docs/components/slider) — Draggable value selector with single or range thumbs, steps, and keyboard control.
- [Switch](/docs/components/switch) — On/off toggle for boolean settings, with size variants and accessible labeling.
- [Tag Input](/docs/components/tag-input) — Input that converts entries into removable pill tags on Enter / comma. Controlled or uncontrolled.
- [Textarea](/docs/components/textarea) — Multi-line text field with intent states and auto-sizing support for comments and messages.
- [Toggle](/docs/components/toggle) — Two-state pressable button for toolbars (bold/italic), with outline and size variants.
- [Toggle Group](/docs/components/toggle-group) — Set of toggles for single- or multi-select segmented controls (alignment, view modes).

## Data Display

- [Avatar](/docs/components/avatar) — User or brand avatar with image, automatic initials fallback, and size variants.
- [Badge](/docs/components/badge) — Compact label for statuses, counts, and tags, with semantic intent colors and subtle/solid styles.
- [Bento Grid](/docs/components/bento-grid) — Bento-style grid layout for feature galleries with mixed sizes.
- [Card](/docs/components/card) — The base surface primitive — header, content, and footer slots — that most composed cards build on.
- [Code Block](/docs/components/code-block) — Code-block chrome: filename header, language badge, copy button, optional line numbers. BYO highlighter.
- [Data Table](/docs/components/data-table) — Dependency-free data grid built on the Table primitives — typed columns, client-side sort, row selection, and pagination out of the box, with a server-side/TanStack escape hatch.
- [Data Toolbar](/docs/components/data-toolbar) — Toolbar layout for tables and data grids — search, filters, and actions in a single bar.
- [Empty](/docs/components/empty) — Empty-state primitive — centered icon, title, description, and action slots for zero-data views.
- [Empty State](/docs/components/empty-state) — Polished zero-data view — icon or illustration, title, description, and a call-to-action button.
- [Feature Card](/docs/components/feature-card) — Feature card with icon, title, and description. The most reused card pattern on any SaaS landing page.
- [Item](/docs/components/item) — Generic list/row primitive with leading media, title, description, and trailing action slots.
- [Kbd](/docs/components/kbd) — Inline keyboard-key styling for documenting shortcuts (⌘K, Ctrl+C).
- [Metric Card](/docs/components/metric-card) — Dashboard metric card with sparkline support and trend indicator.
- [Page Header](/docs/components/page-header) — Page header block with breadcrumbs, title, description, and an action slot for primary buttons.
- [Pricing Card](/docs/components/pricing-card) — Pricing plan card with title, price, feature list, CTA, and an optional 'Popular' pill.
- [Section Card](/docs/components/section-card) — Composable section/landing card with header, content, and footer slots.
- [Settings Section](/docs/components/settings-section) — Settings row layout — label and description on the left, control on the right. For preference screens.
- [Spotlight Card](/docs/components/spotlight-card) — Card with a cursor-following spotlight gradient effect on hover.
- [Stat Card](/docs/components/stat-card) — KPI / metric card with icon, large value, label, and optional delta indicator.
- [Table](/docs/components/table) — Composable data table with header, body, row, cell, and caption sub-components.
- [Team Card](/docs/components/team-card) — Team member card with photo, name, role, bio, and social links.
- [Testimonial Card](/docs/components/testimonial-card) — Customer testimonial card with quote, author name, role, and optional avatar.
- [Tree View](/docs/components/tree-view) — Recursive expand/collapse tree with keyboard navigation, controlled/uncontrolled expansion + selection.
- [User Avatar](/docs/components/user-avatar) — Avatar with image, automatic initials fallback, three size variants, and an optional click handler. The opinionated wrapper most apps reach for.

## Data Visualization

- [Bar List](/docs/components/bar-list) — Horizontal 'top N' ranking list with proportional bar fills. Dashboard staple.
- [Category Bar](/docs/components/category-bar) — Segmented progress bar with per-segment colors and optional labels. Useful for resource breakdowns.
- [Chart](/docs/components/chart) — Composable Recharts wrapper with themed tooltips, legends, and design-system color tokens.
- [Countdown](/docs/components/countdown) — Presentational countdown display (days/hours/minutes/seconds) — pair with the useCountdown hook.
- [Progress](/docs/components/progress) — Linear determinate progress bar for uploads, completion meters, and loading states.
- [Progress Circle](/docs/components/progress-circle) — Circular progress indicator. Radial counterpart to Progress, common for KPI rings.
- [Spark Chart](/docs/components/spark-chart) — Inline mini line/area/bar chart. Pure SVG, no recharts. Tucks inside metric cards.
- [Tracker](/docs/components/tracker) — Uptime/status segment grid. Each block is one period (day/hour) colored by status.

## Feedback

- [Alert](/docs/components/alert) — Inline status banner (info/success/warning/danger) with icon, title, and description for non-blocking messages.
- [Alert Dialog](/docs/components/alert-dialog) — Modal confirmation for destructive or irreversible actions, with required acknowledge and cancel actions.
- [Animated Tooltip](/docs/components/animated-tooltip) — Row of circular avatars that reveal a spring-tilted, mouse-tracking tooltip on hover — for team rows and contributor stacks.
- [Callout](/docs/components/callout) — Emphasized inline message box (info/warning/success/danger). Lives between Alert and Dialog.
- [Dialog](/docs/components/dialog) — Modal overlay for focused tasks and forms, with animated enter/exit and focus trapping.
- [Drawer](/docs/components/drawer) — Mobile-first bottom drawer with drag-to-dismiss physics (Vaul). The touch-friendly Sheet.
- [Hover Card](/docs/components/hover-card) — Rich preview popover that opens on hover — user cards, link previews, and definitions.
- [Notification Center](/docs/components/notification-center) — Bell-icon trigger + dropdown inbox with per-item read/dismiss controls. Composes Button + Popover + Badge.
- [Popover](/docs/components/popover) — Floating panel anchored to a trigger — for pickers, menus, and contextual forms.
- [Sheet](/docs/components/sheet) — Edge-anchored slide-in panel (top/right/bottom/left) for filters, details, and side forms.
- [Skeleton](/docs/components/skeleton) — Animated placeholder block for loading states — mirror your content's shape to avoid layout shift.
- [Toaster](/docs/components/sonner) — Toast notifications — themed, stacked, and promise-aware (Sonner) with Phosphor icons and dark-mode support.
- [Spinner](/docs/components/spinner) — Indeterminate loading spinner (Phosphor CircleNotch) for buttons and async regions.
- [Tooltip](/docs/components/tooltip) — Hover/focus hint label anchored to any element, with configurable delay and side positioning.
- [Top Loading Bar](/docs/components/top-loading-bar) — Slim top-of-page progress bar for Next.js App Router route transitions — self-trickling when animated, a flat aria-live bar when reduced-motion.

## Navigation

- [Breadcrumb](/docs/components/breadcrumb) — Hierarchical navigation trail showing the user's location, with truncation and custom separators.
- [Command](/docs/components/command) — ⌘K command palette with fuzzy search, groups, and keyboard navigation (cmdk).
- [Context Menu](/docs/components/context-menu) — Right-click menu with items, submenus, checkboxes, and keyboard shortcuts.
- [Data Pagination](/docs/components/data-pagination) — Total-driven pagination control — prev/next, numbered pages with ellipsis, an optional page-size selector and an 'X–Y of N' summary. One component wires a whole table footer.
- [Dock](/docs/components/dock) — macOS-style dock bar where icons magnify on cursor proximity. Playful navigation accent.
- [Dropdown Menu](/docs/components/dropdown-menu) — Click-triggered action menu with items, submenus, checkboxes, radio groups, and shortcuts.
- [Menubar](/docs/components/menubar) — Desktop-style horizontal menu bar (File / Edit / View) with dropdowns and keyboard navigation.
- [Navigation Menu](/docs/components/navigation-menu) — Top-level site navigation with animated mega-menu dropdowns and active-link states.
- [Pagination](/docs/components/pagination) — Page navigation with previous/next, page numbers, and ellipsis truncation for long ranges.
- [Sidebar](/docs/components/sidebar) — Collapsible application sidebar system — provider, rail, header/footer, groups, and a full menu (button, action, badge, sub-menu, skeleton) with cookie-persisted open state and a ⌘B keyboard shortcut.
- [Stepper](/docs/components/stepper) — Controlled multi-step wizard — a useStepper hook plus Stepper / StepperNav / StepperPanel with linear or non-linear flow, optional steps, and async validation gating.
- [Steps](/docs/components/steps) — Horizontal or vertical step indicator showing progress through a multi-stage flow or wizard.
- [Tabs](/docs/components/tabs) — Switch between panels of related content with keyboard navigation and an animated active indicator.

- [Aspect Ratio](/docs/components/aspect-ratio) — Locks content to a fixed width:height ratio — responsive images, video embeds, and media cards.
- [Carousel](/docs/components/carousel) — Touch/swipe carousel (Embla) with autoplay, looping, and custom controls for galleries and sliders.
- [Collapsible](/docs/components/collapsible) — Single show/hide region with animated open/close. The building block under accordions and disclosures.
- [Resizable](/docs/components/resizable) — Draggable split panes with persistent sizes for dashboards and editor layouts.
- [Scroll Area](/docs/components/scroll-area) — Cross-browser custom scrollbars for overflow regions, keeping native scroll performance.
- [Separator](/docs/components/separator) — Thin horizontal or vertical divider for grouping content and menu sections.
